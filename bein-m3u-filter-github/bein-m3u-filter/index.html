Utiliser avec NexoTV / Stremio

    
NexoTV accepte une URL de playlist M3U ou une source Xtream Codes. Ce fichier téléchargé est local : il faut une URL HTTPS accessible au serveur NexoTV pour l'utiliser dans l'instance publique. Ne mettez pas en public de liens contenant des identifiants. Pour les accès privés, utilisez plutôt un NexoTV auto-hébergé ou une méthode sécurisée fournie par votre opérateur.
